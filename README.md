# Северный свет

Самостоятельная локальная реализация интерактивного туристического лендинга о Мурманске. Проект создан с нуля как удобная основа для дальнейшей переработки. Он не содержит исходный код, тексты или фотографии сайта, использованного как визуальный ориентир.

## Запуск

Проект не требует сборки или установки пакетов:

```bash
cd /workspace/murmansk-studio
python3 -m http.server 8080 --bind 127.0.0.1
```

После запуска откройте `http://127.0.0.1:8080`.

## Структура

- `index.html` — семантическая разметка всех разделов.
- `styles.css` — дизайн, адаптивная версия и сгенерированные графические сцены.
- `app.js` — календарь света, слайдер мест, маршруты, конструктор поездки, часы и анимация сияния.

Все данные находятся в начале `app.js`, поэтому названия, тексты, месяцы, места и маршруты легко заменить без изменения логики интерфейса.

## Приватность

Никаких публикаций или внешних запросов проект не делает. Он полностью автономен и работает локально.
