# Visual and software credits

## Design foundation

The layout and visual language are adapted from Alina Kruhlikova's Murmansk concept:
https://github.com/alinakruhlikova/murmansk

Reference commit: b6a420c5dbb89f76f1a6da3a921a5f9acca87f20.

The original author is credited in the website footer. Original Murmansk text and geographic images are not used as Austin information.

## Austin illustrations

The following SVG files were created locally for this adaptation. They are stylized placeholder art, not photographs, surveyed panoramas, or documentary views. They should not be used to identify a particular real building, venue, swimming area, or route.

| File | Intended subject |
| --- | --- |
| skyline.svg | A city skyline above a lake |
| night.svg | City lights reflected in water |
| bridge.svg | A stylized bridge and bats |
| springs.svg | A spring-fed-pool-inspired scene |
| capitol.svg | A stylized capitol building |
| hills.svg | Hill Country-inspired hills and river |
| music.svg | An imaginary live-music venue |
| congress.svg | A South Congress-inspired streetscape |

The animated skyline and water are generated with Canvas. They are also illustrations.

No external image requests are made by this website.

## Typography

Font files were obtained from npm's Fontsource distribution, version 5.3.0:

- @fontsource/dela-gothic-one: Dela Gothic One, Latin, 400.
- @fontsource/inter: Inter, Latin, 400 / 500 / 600 / 700.
- @fontsource/tenor-sans: Tenor Sans, Latin, 400.

The Fontsource packages' license files are retained in assets/fonts/. Fonts are served locally and require no Google Fonts connection.
